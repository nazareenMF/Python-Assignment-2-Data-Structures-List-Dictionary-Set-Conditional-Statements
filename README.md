# Python Assignment 2: Data Structures and Conditional Statements
This project contains a completed Jupyter Notebook focused on practicing fundamental data structures in Python—specifically lists, dictionaries, and sets—as well as writing basic conditional statements.
## Overview
This assignment covers key concepts that form the foundation of everyday Python programming:

1. Lists: Creating lists, reading elements with basic and step slicing, modifying items, sorting, and using built-in math functions like max, min, and sum.
2. Dictionaries: Storing key-value pairs, accessing and updating specific entries, and retrieving dictionary keys, values, and items using standard methods.
3. Sets: Understanding how sets handle unique items, demonstrating why indexing isn't supported, and performing set operations like union and intersection.
4. Conditional Statements: Building an interactive script using if, elif, and else blocks to categorize a user's input score and provide meaningful feedback.

## What's Inside the Notebook

### 1. List Operations

* List Creation: Setting up numerical and string lists.
* Modifications: Practice with appending, inserting at specific indexes, popping, removing values, extending lists, and sorting in reverse order.
* Indexing and Slicing: Fetching first and last items, pulling a range of elements, and reversing a list using slicing.
* Built-in Functions: Calculating the maximum, minimum, and overall sum of numeric lists.

### 2. Dictionaries

* Creating a dictionary mapping student names to test scores.
* Reading individual scores using dictionary keys.
* Inserting new entries and updating existing student records.
* Extracting structural data using `.keys()`, `.values()`, and `.items()`.

### 3. Sets

* Seeing how Python automatically removes duplicate values when creating a set.
* Testing set mutability and learning why direct item assignment (like `my_set[0] = 'a'`) results in a TypeError.
* Calculating the union and intersection between two sets.

### 4. Interactive Performance Checker

A simple user-driven program that accepts a score from 0 to 10 and provides feedback based on performance:
* Above 7: Classified as "Above Average" with encouraging feedback.
* Between 4 and 7: Classified as "Average" with advice to keep practicing.
* Below 4: Classified as "Below Average" with constructive advice for improvement.
* Outside 0–10: Handles invalid numerical entries gracefully.
